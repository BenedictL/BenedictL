## 🧬 About Me

> *"Bridging the gap between wet-lab biology and production-grade software engineering — one pipeline at a time."*

I'm a **Senior Analyst turned Computational Biologist**, currently pursuing my **M.Sc. in Bioinformatics at Freie Universität Berlin** (Sep 2024). With **4 years at Accenture India** managing Azure cloud infrastructure at scale, I bring enterprise engineering discipline to biological research.

My thesis project **SnakeLLM** asks: *can we fine-tune a small open-source LLM to generate reproducible Snakemake bioinformatics pipelines better than GPT-4o?*

- 🐍 Fine-tuning **Qwen2.5-Coder-7B** via QLoRA/TRL on curated Snakemake pipeline datasets
- 🔍 Two-stage **RAG pipeline** (ChromaDB + BM25 hybrid + BioContainers URI grounding)
- 📊 Rigorous **360-run benchmark** comparing fine-tuned model vs. frontier LLMs
- ☁️ Training on **GCP (G2/L4 GPU, spot instances)** with model versioning via GCS
- 🔬 Side project: **Silent Mutation Re-Evaluator** — splicing-disrupting synonymous ClinVar variants via AlphaGenome
